P&ID TAG REGISTER

WESSEX WATER DS310 · OFFLINE TOOL · HOW TO USE

WHAT THIS TOOL DOES

Extracts every function tag from your Plant 3D–exported P&ID PDFs, builds a searchable master register, detects clashes, and helps you plan new tag numbers — all without any internet connection or AI involvement. It runs entirely in your browser.

GETTING STARTED

STEP 01
Load your P&IDs
Drop one or more PDF drawings into the Add P&ID Drawings zone. You'll be asked for the revision (e.g. C01, C02, IFD). You can load multiple drawings at once.
STEP 02
Review the register
The All Tags tab shows every confirmed tag. Use the filters to narrow by type, process area, or drawing. The ⚠ Clashes tab flags any duplicate tags across sheets.
STEP 03
Check the Review tab
The ? Review tab contains tags that were found but don't perfectly match DS310 format. Inspect these manually — they may be real tags or noise.
STEP 04
Export your register
Click Export CSV to save the full register. Upload it to Autodesk Construction Cloud for the team. Next time, load the CSV back in and add new drawings on top — it merges automatically.
STEP 05
Plan new tags
Use the ⊕ Next Tag tab. Enter a PAC and FC (e.g. 71, P) to see what's already taken, spot any sequence gaps, and get the next available number instantly.
STEP 06
Review by process area
The ◈ PAC Dashboard shows each process area's tag ranges, type breakdown, and which drawings cover it — useful for sense-checking a new design.

TAG FORMAT — DS310

This tool is calibrated to the Wessex Water DS310 tagging standard. Tags follow the format:

PAC – FC – NNNNN (A)

  • PAC — Process Area Code (1–2 digits, e.g. 71 = Chemical Dosing)
  • FC — Function Code (1–6 letters, e.g. P = Pump, LIT = Level Indicating Transmitter)
  • NNNNN — 3–5 digit identification number (e.g. 1901)
  • (A) — Optional parallel plant suffix A, B, C for duty/standby (e.g. 71-P-1901A)

KNOWN LIMITATIONS

🖨️
Scanned / image-based PDFs will not work. The tool reads the text layer that Plant 3D embeds in the PDF. If a drawing has been scanned or printed to PDF without a text layer, no tags will be found. The tool will warn you if this happens.
📄
Sheet cross-references can confuse the ID number. Where a sheet reference number (e.g. 4001) appears immediately before a tag's ID in the PDF text, the tool may capture the wrong number. Check LCP and MCP tags in particular — these are the most common culprits. They will still appear in the register but may need manual correction.
📏
Line numbers can look like tags. Pipe line numbers with a single-digit area code and a pipe material FC (e.g. 6-FW-1001) match the tag pattern. These are sent to the Review tab automatically, but you should verify them.
🔠
Fully corrupted OCR text won't be caught. If a drawing has been through OCR that replaced hyphens with spaces and garbled letters, the tag may not be recoverable. Em-dashes and double-dashes are handled, but completely mangled text is not.
🔁
The register is not saved between sessions. Export your CSV after every session and reload it next time. The tool has no database — everything lives in the browser tab while it's open.
✏️
The tool extracts, it doesn't validate. It will find tags as written on the drawing. If a tag on the drawing is wrong (wrong PAC, wrong FC, wrong format), the tool will faithfully extract the wrong tag. DS310 compliance checking is your responsibility.

TIPS

  • Load your full drawing set at once rather than one at a time — it's faster and clash detection works across all sheets.
  • If you re-issue a drawing at a new revision, just drop the new PDF in — the tool replaces the old tags from that drawing automatically.
  • The CSV export is designed to be uploaded to Autodesk Construction Cloud as your project master tag register.
  • Use the PAC filter in the main table to focus on one process area at a time when reviewing.
  • Gaps in the ⊕ Next Tag view are worth investigating — they often mean a tag was assigned but never drawn.
